## 🧭 使用流程

1. 点击上方表格中的 **访问链接** 进入站点
2. 完成注册，领取站点宣传的赠送额度
3. 在站点后台获取 **API Key**（请注意保管，勿泄露）
4. 在支持 OpenAI 兼容格式的客户端（如 NextChat、ChatBox、one-api 等）中填入 Base URL 与 Key
