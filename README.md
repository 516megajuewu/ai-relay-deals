## ❓ 常见问题

**Q1：这些站点安全吗？**
A：均为第三方非官方渠道，建议先小额使用验证稳定性，避免大额充值。本站仅做信息整理，不承担任何资金风险。

**Q2：免费额度会过期吗？**
A：各站政策不同，部分站点额度有有效期，建议注册后尽快使用。

**Q3：额度用完可以充值吗？**
A：多数站点支持充值，充值前请务必确认站点长期运营状况。

**Q4：为什么有些站显示"不定时开放"？**
A：部分模型（如 opus-5）受上游供应影响，站点会不定时开放名额，请关注站点公告。
