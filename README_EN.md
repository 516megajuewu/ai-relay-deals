A: All are third-party unofficial services. Start with small usage to verify stability; avoid large top-ups. This repo only organizes info and bears no financial risk.

**Q2: Do free credits expire?**
A: Policies vary by station. Some have validity periods — use them soon after registering.

A: Most stations support top-up. Verify long-term operation before paying.
